# Original action-counter evidence harness

**WIP prototype; not ready for use or real funds.** This unpublished Cargo
package imports the actual `chialisp-oxide-puzzles` increment/reset exports for
native checks. Original Rust policy bodies live only in `puzzles/counter-*` with
shared types in `puzzles/counter_types.rs`. The package library contains aliases.

`capture.py` separates preparation, native checks, extraction, raw replay and
recorded reading. Original extraction compiles the real paired Cargo library in
both modes and admits its entire schema2 inventory before choosing the two
counter exports. Mutants are exact recipes over those fresh original files;
their own materialized crates, native tests and both-mode bundles are separate.
Chialisp and Rue-source compilation use the actual paired reference sources.
All99 vectors preserve opaque ephemeral atom bytes and improper trees and
exercise exact strict environments, owner width, canonical u64 bounds/padding,
checked overflow and actual-source mutant differences.

The normal `protocol` Cargo example composes the selected actions with retained
canonical action-layer, finalizer, launcher and singleton programs. The matching
independent Python reader checks state, ordering, Merkle proofs, raw curry and
solution bytes, exact conditions, actual child identities and typed consensus
outcomes. Rejected submissions assert complete simulator equality in memory.
Signature controls submit actual invalid signatures; the reader does not prove
BLS. Primary clvmr0.21 and SDK clvmr0.16/consensus0.36/Testnet11 are kept explicit.
Repeated byte-identical captures add no scenario coverage.

Canonical sources live under `corpus/upstream`, including the complete pinned
slot-machine tree and selected pinned SDK counterpart sources. The gate checks
all retained source blobs, Git directory/commit identities, exact artifact
identities and the published PPL3-versus-Cargo-MIT discrepancy. SDK Apache
licensing does not establish an upstream relicense. None of these components
becomes a Rust frontend port through host composition.

Run native Cargo check/test/Clippy separately from the additional CLVM subset
check. Coordinate all host builds before driver extraction and source windows.
Use new output directories and explicit prebuilt dated compiler/driver paths;
never reuse a failed capture or implicitly rebuild the driver. Fresh integrated
captures are required; ignored pre-promotion research reports are historical.

The counter does not implement registry slots or complete issue14. Its fixed
reset capability binds the coin/network, not exact batch order. No live wallet,
funding, Sage integration, compiler-preservation proof, execution authentication
or production-readiness claim follows from the harness.
