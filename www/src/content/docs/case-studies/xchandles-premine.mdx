**WIP prototype. Not ready for use or real funds.** This is a case study of an
existing protocol and a local native host recipe. It is not a new on-chain Rust
port, a CHIP standard, or a general authenticated continuation.

The useful distinction is between a registry's policy and the operator's work
list. A controller can preserve the same state and action root while separate
coin spends perform registrations. The observed premine does not commit to the
unprocessed remainder of its CSV. The inspector below keeps those identities,
observed costs, source pins and local simulator results separate.
