## From a Rust function to a real coin spend

Rust handles names, types, and borrow checks. Oxide lowers a deliberately small
subset of checked MIR into a pure IR. Rue optimizes the result and emits CLVM.
Independent Chialisp references and a ledger simulator make the result inspectable.

## Confidence has a scope

The current compiler is an experimental subset, not a general Rust target or an
audited wallet. The lab exposes measured evidence and the remaining assumptions.
Formal models are labeled separately from end-to-end compiler proofs. Canonical
CHIP module hashes remain compatibility requirements, even when tests agree.

Start with [what works today](/chialisp-oxide/reference/supported-rust/), then read
[the validation method](/chialisp-oxide/verification/method/) before extending a puzzle.
