## Shared Rust CLI and loopback GUI

The local lifecycle crate now shares a closed batch-one recipe between its
`continuation-*` commands and loopback GUI. Fresh native, source-aware compiler,
VM and SDK checks precede preparation. The journal binds the complete queue,
selected module, public wallet identity and fees. Funding and optional fee
sponsorship use purpose-specific signing plans; signing stays in the local
terminal. A durable push intent closes submission after a transport error, so
recovery observes the exact spend and outputs before continuing.

Read the [lifecycle commands and scope](https://github.com/judeallred/chialisp-oxide/tree/main/crates/chialisp-oxide-lifecycle#shared-continuation-trial)
and the [shared Rust state machine](https://github.com/judeallred/chialisp-oxide/tree/main/crates/chialisp-oxide-lifecycle/src/live/continuation).
This closed batch-one workflow is separate from the earlier Python live trial
and the batch-two simulator comparison. It is not a generic continuation SDK.
