The local chialisp-highlighting.mjs is a modified TextMate adaptation of the
official Prism token categories and palette, not an unchanged upstream file.
Changes include modern keyword/operator coverage, exact literal boundaries,
Shiki/Expressive Code integration and accessible light/dark contrast handling.
The upstream theme credits https://github.com/dracula/visual-studio-code as its
original palette source. No upstream theme implementation is vendored here.
