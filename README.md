# clispOx

Rust → CLVM compiler tooling, built on Rue, with executable tutorials,
differential puzzle tests, and an evidence-based study of prevented errors.

This repository is in the research and design phase. No compiler is implemented yet.

- [Project goals](goals.md)
- [Compiler approach and implementation plan](docs/compiler-approach.md)
- [Chialisp reference and tutorials](https://chialisp.com/)

The recommended first milestone is one real, rustc-checked puzzle compiled through
reused Rue compiler infrastructure and executed by CLVM, with matching native Rust and Chialisp test results.
